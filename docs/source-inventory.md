# Происхождение, комплектность и права

## Источники

1. Доступное окончание разговора «Прошивка роутера Huawei»: пять обменов про AdBlock, исправления HTML и итоговую конфигурацию.
2. Чтение файлов установленного роутера по Telnet 4 октября 2026 года (Europe/Moscow).
3. Проверка HTTP панели и диагностических CGI; только обезличенные результаты попадают в документацию.
4. [Общий upstream Huawei LTE routers modifications](https://github.com/Huawei-LTE-routers-mods/README) и [инструменты сборки](https://github.com/Huawei-LTE-routers-mods/huawei_balong_modfw_kitchen).

Все 12 файлов `src/statusweb` и `src/zoid-dns` сохранены побайтно и проверены по SHA-256 на устройстве. [Манифест](source-manifest.json) содержит исходные пути и хеши. Пользовательские секции autorun и HTML кнопки извлечены отдельно; их переводы строк приведены к LF. Полные исходные системные файлы и gzip WebUI сохраняются в локальном рабочем архиве вне репозитория.

## Что сохранено

| Компонент | Где |
| --- | --- |
| Итоговый HTML панели и три CGI | `src/statusweb/` |
| Watchdog | `src/statusweb/watchdog.sh` |
| Применение и восстановление DNS | `src/zoid-dns/dns_profile.sh`, `dns_autorun.sh` |
| Все 17 строк таблицы профилей | `src/zoid-dns/profiles` |
| Исходный и сгенерированный Stubby YAML | `src/zoid-dns/stubby.original.yml`, `stubby.yml` |
| Текущий профиль и AdBlock | `src/zoid-dns/profile`, `adblock` |
| Штатные файлы состояния DNS, TTL и Anticensorship | `config/device-state/`; снимок, не установочные файлы |
| Пользовательская секция существующего autorun | `integration/oled-autorun.append.sh` |
| Кнопка штатного WebUI | `integration/deviceinformation-button.html` |
| Штатные dnsmasq-конфигурации как справочный материал | `config/firmware-reference/` |
| Сборочные пути, зависимости, режимы, проверка и ограничения | `docs/` |

`/app/webroot/status.html` содержал только тестовую строку `E5372 status test`. Он сохранён локально для полноты, но не включён в исходники рабочего проекта: рабочая страница обслуживается другим HTTP-сервером из `/data/userdata/statusweb`.

Штатные `/system/etc/autorun.sh`, `/app/appautorun.sh`, `/etc/dns_over_tls.sh`, оболочки `dns_over_tls`, `ttl`, `anticensorship`, `adblock_update`, версия модификации, исходный gzip страницы WebUI и её JS сохранены локально как справочные материалы. Это зависимости базовой прошивки; собственных изменений панели в них не обнаружено, кроме отдельно сохранённых секций OLED autorun и HTML кнопки. В публичный набор не включены полные копии этих компонентов.

## Что не получено

Полная ранняя история прошивки, точные установочные пакеты и их хеши, аппаратный суффикс модели, инструкция аварийного восстановления загрузчика, первоначальные резервные копии до модификаций. Device API вернул ошибку доступа, однако версия `21.290.23.00.00` подтверждена через `AT+CGMR`, модель E5372 — через `AT+CGMM`. Сведения о Fast Boot/USB остаются из старого разговора. Пользователь уточнил экранное меню: Remote access = Web + Telnet, ADB выключен. Работающий `adbd` и отсутствие флага `adb_disable` сами по себе не доказывают доступность ADB через USB; USB-подключение не проверялось.

## Права

Пользовательские файлы панели и скрипты `zoid-dns` получены как результат работы пользователя и ассистента. Шаблон Stubby и dnsmasq-конфигурации происходят из установленной прошивки. Кнопка использует API штатного WebUI, но сохранён только добавленный пользовательский блок, без полной страницы Huawei.

Общая лицензия для всего набора ещё не назначена. Перед публикацией с лицензией следует проверить происхождение заимствованных конфигураций и выбрать условия для пользовательской части отдельно. Ссылки на upstream не являются лицензией. Архив не включает исполняемые файлы BusyBox/Stubby/dnsmasq или образы прошивки.
