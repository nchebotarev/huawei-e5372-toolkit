# Проверка архива

Дата сбора: **4 октября 2026 года**, Europe/Moscow.

## Проверено на работающем устройстве

- Прочитаны оба пользовательских каталога полностью; 12 файлов скопированы без изменения и сверены по SHA-256.
- Найдены пользовательские секции `/app/bin/oled_hijack/autorun.sh` и кнопка в `deviceinformation.html.gz`.
- `busybox sh -n` завершился с кодом `0` для watchdog, трёх CGI, двух DNS-скриптов и существующего OLED autorun.
- Работали watchdog и `busybox httpd` на 8080, dnsmasq с обычной конфигурацией и Stubby с пользовательским YAML.
- `GET /status.html`: HTTP 200; 24 243 байта; хеш совпадает с сохранённым файлом.
- `GET /cgi-bin/status.cgi`: HTTP 200; корректный JSON, 40 полей. Реальные WAN IP/Cell ID и другая телеметрия в репозиторий не включены.
- `GET /cgi-bin/dotcheck.cgi`: HTTP 200; корректный JSON, `established=true`.
- Состояние: Yandex, AdBlock Off, режим DoT `1`, Stubby Running, Anticensorship Disabled, TTL `64`.
- Версия модификации: v1.5.2, WebUI: `17.100.19.01.03`, BusyBox: `1.29.3`, архитектура `armv7l`.
- `AT+CGMR` подтвердил `21.290.23.00.00`, `AT+CGMM` — E5372; эти команды не читают IMEI/серийные номера.
- Процесс `adbd` работает, файлы `adb_disable` и `telnet_disable` отсутствуют. Пользователь уточнил состояние экранного меню: Remote access = Web + Telnet, ADB выключен. Наличие процесса не подтверждает доступность ADB через USB; USB-подключение при сборе не проверялось.

Чтение `/api/device/information` не дало версии устройства: API вернул ошибки доступа. Версия подтверждена отдельно через AT, однако строка в CGI по-прежнему задана вручную и сама не отслеживает смену прошивки.

## Локальная проверка

Проверены контрольные суммы копий, LF всех исходников, синтаксис встроенного JavaScript и инструмента подготовки WebUI. На копии фактической gzip-страницы успешно проверены удаление/добавление блока, сохранность остальных байтов и отказ при дубликатах/перезаписи входа. Относительные ссылки документации проверены. Проверка содержимого публикуемого набора на переданный пароль, длинные числовые идентификаторы, MAC-адреса, токены GitHub, приватные ключи и буквальные session cookies не обнаружила совпадений; исходники дополнительно просмотрены.

## Не выполнялось

Роутер не перезагружался, DNS-профиль не переключался, AdBlock не включался, пароль не менялся. Переустановка, новые права файлов, инструмент установки кнопки и инструкции отката на устройстве не испытывались. Исходники не исправлялись при архивировании; обнаруженные проблемы описаны в [ограничениях](limitations.md).
