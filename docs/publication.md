# Публикация

Публичный репозиторий: [nchebotarev/huawei-e5372-toolkit](https://github.com/nchebotarev/huawei-e5372-toolkit). Имя, структура и публичная видимость согласованы с пользователем до публикации.

В публикацию входит только содержимое каталога `huawei-e5372-toolkit/`: 36 подготовленных файлов. Соседний локальный каталог сбора, архивы с роутера, сырые ответы HTTP и исходный разговор не входят в этот набор.

Пароль и сведения для входа по Telnet в репозиторий не записаны. Парольные файлы, настройки SIM/Wi-Fi, IMEI, IMSI, ICCID, серийные номера, MAC-адреса и живые значения телеметрии не включены. Публичные адреса DNS-провайдеров и стандартный LAN IP роутера являются необходимой частью конфигурации.

Набор проверен на секреты до первого коммита с исходниками. Общая лицензия не назначена: происхождение пользовательских файлов и конфигураций описано в [инвентаризации](source-inventory.md). При последующих изменениях проверяйте также публикуемую историю; исходные секретные материалы нельзя сначала коммитить, а затем просто удалять из последнего состояния.

`.gitignore` исключает типовые дампы и локальные резервные материалы. Это дополнение к проверке содержимого, а не гарантия отсутствия секретов.
