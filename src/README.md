# Итоговые исходники

`statusweb/` и `zoid-dns/` скопированы с устройства без изменения содержимого. Все 12 файлов проверены по SHA-256 на стороне роутера. Пути, размеры и хеши: [манифест](../docs/source-manifest.json).

Параметры `profile=yandex`, `adblock=0` и сгенерированный `stubby.yml` отражают состояние при архивировании. `stubby.original.yml` — исходный шаблон генератора, а не резервная копия перед будущими изменениями.

Интеграция с существующей прошивкой находится в `../integration/`. `../tools/patch-webui.py` — новый локальный инструмент подготовки кнопки, созданный при архивировании; на роутере такого инструмента не было.
