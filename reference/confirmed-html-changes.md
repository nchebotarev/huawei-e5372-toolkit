# Подтверждённые изменения HTML

Источник: команды и подтверждения в доступном окончании исходного разговора. Обе правки затем подтверждены в полном итоговом [`status.html`](../src/statusweb/status.html), скопированном с устройства 4 октября 2026 года. Эти фрагменты поясняют изменения и не являются установочным патчем.

Путь на роутере: `/data/userdata/statusweb/status.html`.

## Статус DoT

Исходное условие проверяло только `d.dns_dot === "1"`. Финальное условие для текста:

```javascript
(d.dns_dot === "1" || d.dns_dot === "2") ? "Enabled" : "Disabled"
```

Для класса цвета:

```javascript
(d.dns_dot === "1" || d.dns_dot === "2") ? "good" : ""
```

Пользователь прислал команды замены обоих условий; в итоговом файле подтверждены текст и цвет для режимов `1` и `2`.

## Подпись AdBlock

```html
<option value="1">On (high memory usage)</option>
```

Пользователь подтвердил появление подписи. Значение `1` относится к пункту выбора в HTML; оно не должно автоматически отождествляться с режимом файла `dns_over_tls` без проверки CGI. По замыслу этой правки менялась только подпись.
